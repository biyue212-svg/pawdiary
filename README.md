# 爪爪日记 PawDiary

宠物成长记录与社区，手机端优先。支持狗、猫、鸟、蜥蜴、仓鼠、兔、龟、鱼和其他宠物。

## 已实现
- 宠物档案、成长时间线、相册、健康记录与站内护理计划；小体型宠物默认使用克，可在 g/kg 之间切换。
- 不同宠物的护理入口、类型筛选、同城示例宠友及社区图文演示。
- 小狗头像品牌图标、网站 favicon 与桌面鼠标。
- 真实在线意见收集：匿名提交、可选联系方式、失败重试、回执、限流及重复提交去重。反馈保存在 D1；没有公开读取接口。网站所有者可通过 Sites 数据工具查看。
- 成长记录、社区互动与邀请原型保存在当前浏览器。旧版记录兼容保留。

## 开发与部署

使用随项目提供的 Vinext/Cloudflare 配置，安装依赖后运行 `npm run dev`。
`npm run db:generate` 生成迁移；`npm run build` 构建；发布时应用 drizzle 中的迁移。
界面文件在 public/，根路由通过 lib/pawdiary-page.ts 保留原网页；反馈接口在 app/api/feedback/route.ts。

线上地址：https://pawdiary-yue-1104.taoxinran3.chatgpt.site

GitHub 源码同步本身不自动触发该地址部署。

动物照片为已打包的 Unsplash 示例素材；鸟、蜥蜴、仓鼠、兔、龟、鱼及小狗品牌标志为原创 SVG 插画，不代表真实宠友身份。

## 首次体验与轻互动

新访客先选择宠物类型，支持多选与指定先查看的类型；偏好保存在当前浏览器，可在首页或“我的”中修改。没有真实档案时展示清楚标记的对应示例，不会自动创建个人宠物。
品牌采用宠物之家的组合标志与统一物种图标，已移除自定义鼠标。点按宠物可以打招呼；“今日观察”可直接写入成长册，同一天修改会更新原记录。动效遵循减少动态效果设置，不含声音，也不做自动健康判断。
