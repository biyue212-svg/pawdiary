# 爪爪日记 PawDiary

手机端优先的宠物成长记录与社区网页。包含首页、成长、附近、社区、我的五个入口。

- 多宠档案；体重、疫苗、驱虫、日常与里程碑记录，支持图片、编辑、删除和草稿。
- 成长时间线、健康趋势、相册、站内护理计划。
- 示例宠友的地区、体型、性格、交友意向与时间筛选。
- 社区发布预览、成长册同步、评论、收藏与关注的本机原型。
- 示例／个人数据隔离；兼容旧版 `pawdiary-records`；支持 JSON 导出备份。

## 运行

本项目没有第三方运行时依赖。以任意静态服务器运行本目录即可，例如 `python3 -m http.server 8080`。

## 数据边界

记录保存在当前浏览器。社区、宠友与邀请为明确标记的交互演示，没有真实多人服务、消息发送或后台通知。图片素材已打包，不依赖外部图片 CDN 加载。
